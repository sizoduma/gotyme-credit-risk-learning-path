# GoTyme Credit Risk Learning Path 🏦

## Quick Start

Welcome to the comprehensive learning path for mastering credit risk modeling, IFRS 9 ECL, and production MLOps for GoTyme MCA.

### 📚 Core Curriculum
- **[CURATED_LEARNING_PATH.md](CURATED_LEARNING_PATH.md)** — Complete 16-week curriculum with weekly breakdowns

### 🎯 What You'll Learn

✅ **Credit Risk Modeling** (PD, LGD, EAD estimation)  
✅ **IFRS 9 ECL Compliance** (Staging logic, regulatory calculations)  
✅ **Model Interpretability & Governance** (SHAP, auditing, documentation)  
✅ **MLOps & Monitoring** (Drift detection, model performance tracking)

✅ **Merchant Cash Advance** (MCA-specific risk patterns)
